## Project Description
I’m currently working on a project called AppXpert with a partner, and it’s designed to make the job search experience a lot easier for students. We will be developing it as a mobile app that centralizes everything related to job applications in one place.

The idea is that users can create a secure account to store all their information, like application materials and company details. They can then track their progress and success rates through a dashboard, which really helps visualize their job search journey. Plus, we’ve included a calendar feature for important dates, like application deadlines and interviews, so they never miss anything crucial.

We’re using React Native for the development, Figma for designing the interface, and Detox for testing to ensure everything runs smoothly.
